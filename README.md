# ✈️ Layover Friends

Connect with travelers during airport layovers. Meet people, share experiences, get travel tips.

## 🎯 Features

- **Real-time Chat** — Firestore-powered instant messaging between travelers
- **AI Travel Assistant** — Groq LLM-powered chatbot for multi-turn conversations & travel recommendations
- **Flights Screen** — Live departures/arrivals by airport code
- **OAuth Login** — Seamless Google Sign-In
- **Push Notifications** — Stay connected
- **Mobile & Web** — Flutter Android + Next.js landing page

## 🛠️ Tech Stack

**Mobile:** Flutter, Firebase (Auth, Firestore), Supabase, Groq API, Netlify Functions

**Web:** Next.js 14, Vercel

**AI:** Groq LLM (`openai/gpt-oss-20b`), FastAPI service
